# Number Guessing Game 🎮

A beginner-friendly Number Guessing Game built using Python.

## Features

- Generates a random number between 1 and 100
- Allows multiple guesses
- Gives hints when the guess is too high or too low
- Counts the number of attempts
- Handles invalid input
- Allows the player to play again

## Concepts Used

- Variables
- `random` module
- `random.randint()`
- Input and output
- If-else statements
- While loops
- Break statement
- Try-except error handling
- String methods

Make sure Python is installed.

Run the program using:
